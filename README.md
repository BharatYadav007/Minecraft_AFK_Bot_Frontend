# Minecraft AFK-Bot Frontend

Source-only Next.js/React dashboard for the Mineflayer backend.

Views included: multi-bot dashboard, add-bot modal, bot status, connect/disconnect/reconnect, Anti-AFK toggle, telemetry, live Prismarine Viewer iframe, movement controls, pathfinding coordinates, and chat/command console.

Expected libraries when you wire dependencies later: next, react, react-dom, socket.io-client.
